<objective>
Close UAT gap 3: the New Collection dialog's footnote overlaps the last preview line, and the Choose dialog clips a wrapped strip row to its first line.

Purpose: both dialogs call `setMinimumWidth(560)`, which gives the window an explicit minimum size, so the layout's default size constraint no longer raises the window's minimum height to what the layout needs; Qt then lays the dialog out below its size hint and the fixed-height preview and the footnote overlap (UAT: preview bottom 301, footnote top 276-285). Word-wrapped labels report their height through height-for-width, which a top-level window does not apply to itself, so a strip row that wraps keeps a one-line height (UAT s2_02). A scratch probe this session reproduced both in the test process with the default offscreen platform (New Collection: preview bottom 311 vs footnote top 255; Choose rows 6 px tall for a height-for-width of 12 to 54) and showed the fix: after setting the minimum height to `max(layout.totalMinimumSize().height(), layout.totalHeightForWidth(width))` and resizing to it, the footnote sits below the preview, every row is as tall as its text, and `resize(560, 10)` cannot shrink the dialog below it.
Output: `fit_height_to_content` in new_collection_dialog.py wired into both dialogs; shared geometry checks; in-process tests at the default scale; a child-process run at QT_SCALE_FACTOR 1.75.
</objective>
