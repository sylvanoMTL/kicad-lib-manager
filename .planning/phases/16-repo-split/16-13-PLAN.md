<objective>
Live run, part 1 (interactive): prepare the main checkout KiCad reads for the split, behind a read-only preflight and an owner decision. Bundle both repositories, make both GitHub repos private, merge `feature/part-importer` into `main` in the main checkout, push `main` and `v2.0`, delete the stray branches and tag `pre-split`.

Purpose: SPLIT-07 (visibility of both existing repos decided and set: private, D-11), D-06 (the pre-split housekeeping), D-23 (bundles and the pre-split tag before the live steps), and the D-22 baseline for SPLIT-02.

The owner closes the app running from the main checkout before Task 3.
