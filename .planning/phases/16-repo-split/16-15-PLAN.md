In the main checkout KiCad reads, make the remove-code commit with `cutover_collection.py`, prove with the URI diff that every KiCad table URI still resolves the same with zero missing, push the private collection, start the app from the tool checkout's own env on the main checkout, and retire the main checkout's old venvs.
