Remove the Phase 15 legacy own-folder fallback (`Source.LEGACY`, "the folder this app runs from"), locked in CONTEXT ("Locked from earlier phases"). Purpose: SPLIT-08 (the tool runs against a chosen collection, never against its own folder). This also lifts the STATE.md note "first-run window cannot appear when the app runs from a checkout that is itself a collection (by design until Phase 16)".
Output: collection.py, startup.py, main_window.py and help_dialog.py without the fallback; the tests that pinned it deleted or rewritten. The CLAUDE.md bullet that names it is rewritten by plan 16-07.
</objective>
