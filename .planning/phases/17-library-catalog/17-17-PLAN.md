  <name>Task 1: Owner adds SparkFun, 4ms, Alternate-KiCad-Library and Espressif in a scratch collection and records each result</name>
  <read_first>
    - CLAUDE.local.md (the owner's folders; never copied into a plan or summary)
    - .planning/phases/17-library-catalog/17-RESEARCH.md (section "Real verification of the curated candidates", the expected numbers)
  </read_first>
  <action>Run the catalog for real on the owner's machine in a scratch setup and report the numbers; Claude has built and tested everything that can run without the network.</action>
  <instructions>
    Needs about 2 GB free and the network. PowerShell, from the tool checkout; `<scratch>` is a new empty folder outside every repository (for example under your backup folder named in CLAUDE.local.md).
    1. Make a scratch KiCad settings folder: `New-Item -ItemType Directory <scratch>\appdata\kicad\10.0 -Force` and copy your real `kicad_common.json` of KiCad 10.0 (folder in CLAUDE.local.md) into it.
    2. In the same PowerShell window: `$env:APPDATA = "<scratch>\appdata"` then `.\env\Scripts\python.exe kicad_lib_manager.py`. Use File > New Library Collection... to create `<scratch>\collection`; answer the path-variable question with Yes (it changes only the scratch settings).
    3. File > Library Catalog... (Ctrl+Shift+L). Select SparkFun: check the licence page says CC BY 4.0 with no tick, press Download and Check, watch the progress, check the preview (about 30 symbol and 21 footprint libraries, no name clashes), press Add Library. In the main window: the SparkFun libraries appear ticked; the path-variable question for SPARKFUN_KICAD_LIBRARY opens: Yes. Note from the log: the number of "3D model not found" warnings (about 6 expected), the download time, and the size shown in the Details page. Then Remove This Library and check the folder is gone.
    4. Same for 4ms KiCad Libraries (Unlicense, about 25 and 29 libraries, KICAD_4MS_LIBS, 0 missing models expected).
    5. Add by URL...: `https://github.com/DawidCislo/Alternate-KiCad-Library`. Note the licence shown (and the tick asked on the preview), the counts (about 39 symbol and 63 footprint libraries), the name-clash list, the scan time and the model warnings. Keep it if it works and you want to; Remove it otherwise.
    6. Add by URL...: `https://github.com/espressif/kicad-libraries`. Check the preview shows "... 3D models use KiCad's own path variables ..."; press Discard Download.
    7. Close the app and the PowerShell window (APPDATA goes back to normal).
  </instructions>
  <verification>The owner's report gives, per library: pass or fail, the reason for a fail, counts, model warnings, download time and disk size; Espressif's warning seen.</verification>
  <resume-signal>Paste the results per library (SparkFun, 4ms, Alternate-KiCad-Library, Espressif), or "stop" with what went wrong.</resume-signal>

    - The report confirms the real KiCad settings and the main checkout were not used (APPDATA pointed at the scratch folder; the collection was the scratch one).
  </acceptance_criteria>

  <name>Task 2: Owner checks Cancel, an offline start, a real update and (optionally) a private address</name>
  <read_first>

  </read_first>
  <action>Check the behaviours only a real network and a real desktop show; Claude cannot run them from automation.</action>
  <instructions>
    Same scratch setup as Task 1 (`$env:APPDATA = "<scratch>\appdata"`, then start the app on `<scratch>\collection` with `--library-root <scratch>\collection`).
    1. Cancel: add SparkFun again, press Download and Check, and press Cancel Adding after 2-3 seconds. Check Task Manager shows no git.exe or git-remote-https.exe left, the log says "Stopped adding SparkFun. Nothing was added.", and `<scratch>\collection\ThirdParty\.staging` is empty or absent. Then add SparkFun fully.
    2. Real update: close the app and make the SparkFun copy one commit older: `git -C <scratch>\collection\ThirdParty\SparkFun fetch --deepen=1 origin`, then `git -C <scratch>\collection\ThirdParty\SparkFun reset --hard HEAD~1`, then `git -C <scratch>\collection\ThirdParty\SparkFun rev-parse HEAD` and put that id as SparkFun's "commit" in `<scratch>\collection\catalog.json`. Start the app. After the scan the log says "1 catalog library has an update: SparkFun" and the File menu reads "Library Catalog... (1 update)". In the catalog, Update This Library shows the preview (old -> new version, files changed, libraries added and removed); press Update Library; the menu text goes back to "Library Catalog..." and catalog.json holds the new commit. (If the preview refuses with changed files, report it with the list it shows.)
    3. Offline: disconnect the network, start the app: no catalog line in the log, no popup, plain menu text; the SparkFun Details page says "Could not check for updates (GitHub could not be reached)". Reconnect.
    4. Optional, only if you want to: Add by URL... with the address of one of your private repositories. Expect "GitHub could not find this repository, or it is private. The catalog only adds public repositories." and no Git Credential Manager window. Do not paste the address into the report.
    5. Remove SparkFun, close the app and the PowerShell window; delete `<scratch>` when you no longer need it.
  </instructions>
