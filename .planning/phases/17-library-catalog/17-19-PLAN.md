  <action>Prepare the rehearsal copy and run the catalog part of the conversion on it; it needs the real network and about 30 GB free, which only the owner can provide.</action>
  <instructions>
    PowerShell, from the tool checkout. `<main checkout>` and `<backup folder>` are named in CLAUDE.local.md; `<r>` is a new folder inside the backup folder (for example `<backup folder>\wurth-rehearsal`). Close KiCad.
    1. Copy: `git clone --no-local <main checkout> <r>\collection`; then fill the submodules from the main checkout's local data, with no download: `git -C <r>\collection config submodule.Custom.url <main checkout>/.git/modules/Custom` and `git -C <r>\collection config submodule.WurthElektronik/KiCad-Library.url <main checkout>/.git/modules/WurthElektronik/KiCad-Library`, then `git -C <r>\collection -c protocol.file.allow=always submodule update --init`.
    2. Scratch KiCad settings: copy your real KiCad `10.0` and `9.0` settings folders (CLAUDE.local.md) into `<r>\appdata\kicad\`.
    3. In one PowerShell window: `$env:APPDATA = "<r>\appdata"` then `.\env\Scripts\python.exe kicad_lib_manager.py --library-root <r>\collection`. Answer Yes to the path-variable question (it writes only the scratch settings). Set the Destination to `<r>\appdata\kicad\10.0` and press Generate Tables once, so the scratch tables point at the copy.
    4. Before snapshot (second PowerShell window, normal APPDATA is fine because the paths are explicit): `.\env\Scripts\python.exe scripts\split\uri_diff.py snapshot --tables-dir <r>\appdata\kicad\10.0 --config-dir <r>\appdata\kicad\10.0 --lib-root <r>\collection --no-env --out <r>\before.json`.
    5. In the app: File > Library Catalog... > Würth Elektronik > Add This Library; tick "I have read the licence terms"; Download and Check (several GB: note the time); check the preview (about 402 symbol and 43 footprint libraries, WE_3DMODEL_DIR -> 3dmodels); Add Library. Check the log line "Moved {n} selected libraries from WurthElektronik/KiCad-Library to ThirdParty/WurthElektronik ..." (about 89 expected) and answer Yes to the WE_3DMODEL_DIR question.
    6. Press Generate Tables, then Rescan Libraries: note any "3D model not found" or "Footprint library ... not found" line for Würth (zero expected).
    7. After snapshot: the step 4 command with `--out <r>\after.json`.
    8. Note the disk use of `<r>\collection\ThirdParty\WurthElektronik`. Keep the app open for Task 2.
  </instructions>
